# FC-05 backfill, FC-06 adaptive adapters, FC-07 content types

Status (2026-11-15): **code complete with fixtures**; no live source traversed.

## FC-05 — `foia_archive/backfill.py`
* `plan_backfill(source_id, start, end, months)` creates `PENDING` date windows
  on the FC-02 cursor ledger (idempotent); each window is a replayable checkpoint.
* `missed_period_queue()` lists unfinished (`PENDING`/`IN_PROGRESS`/`FAILED`)
  windows oldest-first across sources; `BLOCKED` windows are excluded, not retried.
* `backfill_status()` gives verified oldest/newest windows and expected-vs-seen
  counts where the source declares totals.
* `release_windows()` gives per-source oldest/newest published year, records
  per year, empty years inside the span and undated records. Years are metadata only.

## FC-06 — `foia_archive/adapters.py`
* `detect_site_type()` → `sitemap`, `json_api`, `pal`, `html_listing`,
  `document`, `challenge`, `unknown`.
* `raise_if_blocked()` turns 401/403 and CAPTCHA/challenge pages into
  `SourceAccessBlocked` (FC-02 records `BLOCKED`; nothing is solved or evaded).
* `sitemap_pager()` walks sitemap indexes breadth-first as an FC-02 cursor;
  same-host URLs only; DTD/entity declarations anywhere in the document are
  refused; size and fan-out limits.
* `parse_json_listing()` maps documented public JSON APIs by dotted paths
  (items, URL field, next link restricted to the source host, declared total).

## FC-07 — `foia_archive/content_types.py`
* `sniff()` identifies PDF, OOXML (docx/xlsx/pptx), OLE legacy Office, ZIP,
  images, RTF, audio/video and text by signature.
* `safe_zip_members()` expands bundles under member-count, per-member,
  total-size, compression-ratio (100×) and nesting (1) limits, with bounded
  reads, and rejects traversal paths, symlinks and encrypted members.
* `format_coverage()` reports per archived format INDEXED / EMPTY /
  UNSUPPORTED / FAILED / NOT_ATTEMPTED and indexed % of *attempted* only.
Wiring bundle expansion into the downloader and audio/video transcript
metadata are follow-ups.
